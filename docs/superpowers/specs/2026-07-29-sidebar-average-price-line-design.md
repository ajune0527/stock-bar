# 侧栏分时均价线设计

## 目标

在侧栏个股分时图的价格区域增加当日累计均价线。均价直接使用东方财富
`trends2/get` 返回记录的第 4 个字段，不根据分钟末价和成交量重新估算。

## 数据模型

东方财富分时记录当前解析为：

```text
时间,价格,成交量,累计均价
```

`TrendData` 新增明确的 `averagePrice` 字段。暂时保留现有 `amount` 字段，
并赋相同值，以兼容尚未迁移的消费者；新增代码只使用 `averagePrice`。

无效、空白或非有限均价值转换为 `0`。绘图时忽略小于等于 `0` 的均价点，
不做成交量加权回退计算。

## 绘图

- 均价线位于现有价格图区域，与分时价格线共享时间轴。
- 使用黄色/橙色实线，与红绿分时价格线区分。
- 价格轴范围同时包含分时价格、有效均价和昨收价。
- 均价线不绘制渐变填充，不进入成交量区域。
- 顶部增加紧凑图例，用线段和文字区分“现价”和“均价”。
- 只有一个有效均价点时显示该点；连续有效点绘制折线。

## 测试与验证

- 测试东方财富记录第 4 个字段同时映射到 `averagePrice` 和兼容字段
  `amount`。
- 测试静态图表 HTML 使用 `point.averagePrice`、包含均价颜色和图例。
- 运行侧栏图表及 AxData 聚焦测试、TypeScript 编译、范围 lint 和生产构建。

## 非目标

- 不自行计算 VWAP。
- 不改变 AxData 实时行情协议。
- 不新增均价显示配置或颜色配置。
