# 侧栏个股分时图设计

## 目标

在 VS Code 的 `stockBar` 侧栏容器中，为原生自选股 Tree View 增加一个
固定的分时图视图。用户单击任意股票后，下方视图展示该股票的价格分时曲线
和成交量，不打开编辑器标签页或弹窗。

## 交互与布局

- 保留现有自选股 Tree View、市场 Tab、拖拽排序和右键菜单。
- 在自选股列表下方贡献 `stockBarTrend` Webview View。
- 两个视图使用 VS Code 原生分隔条，可独立折叠和调整高度。
- 单击股票节点时切换图表；单击市场 Tab 或空状态节点不改变当前图表。
- 图表尚未选择股票时显示“点击上方个股查看分时图”。
- 图表顶部显示股票名称、代码、当前价、涨跌额和涨跌幅。
- 提供刷新按钮，用户可主动重新拉取当前股票的分时数据。

## 图表

图表使用 Canvas 绘制，不加载外部前端框架：

- 上部约 72% 为价格分时曲线、渐变填充、昨收参考线、价格刻度和网格。
- 下部约 28% 为逐分钟成交量柱状图。
- 价格区和成交量区共享时间轴。
- 成交量柱按当前分钟价格相对上一分钟价格着色；首分钟相对昨收价着色。
- A 股、港股和美股分别使用已有市场交易时段配置。
- 当视图宽高变化时自动按设备像素比重绘。

## 组件

新增 `StockTrendViewProvider`，职责是：

- 实现 `vscode.WebviewViewProvider` 并维护 Webview View 生命周期；
- 维护当前选中的股票代码；
- 请求并缓存现有 `eastMoneyProvider.getTrends()` 数据；
- 将股票元数据、实时行情和分时数据发送给 Webview；
- 处理刷新请求、加载状态、空数据和错误状态；
- 在选中股票被删除时清空视图。

`StockBarController` 继续负责股票集合，并：

- 注册 `stockBarTrend` Webview View；
- 监听 `TreeView.onDidChangeSelection`；
- 将选中的股票交给 `StockTrendViewProvider`；
- 每次实时行情渲染时同步当前股票的顶部报价，但不重新请求分时数据。

## 数据流与缓存

1. 用户单击 Tree View 中的股票。
2. 控制器把 `Stock` 交给 `StockTrendViewProvider`。
3. 提供器立即显示该股票的最新报价和加载状态。
4. 若缓存中已有该代码的分时数据，则直接绘制；否则调用
   `eastMoneyProvider.getTrends(stock.getSecid())`。
5. AxData 或东方财富更新报价时，仅发送 quote 消息更新顶部信息和昨收线。
6. 用户点击刷新时绕过缓存并重新请求。

缓存按完整 `secid` 区分市场，防止不同市场的相同代码互相覆盖。切换请求使用
代次标记，较慢的旧请求不得覆盖后来选中的股票。

## 错误与边界

- 分时请求失败时显示简短错误和重试按钮，不影响股票列表和实时行情。
- 空数据时显示“暂无分时数据”，成交量区域保持空白。
- Webview 尚未展开或重新创建时保留当前选择，创建完成后恢复显示。
- 自选股重载时按市场和代码重新关联当前股票。
- 当前股票被删除时清空选择和缓存引用。
- 所有注入 Webview 的文本和序列化数据必须安全编码，股票名称不得直接拼接为
  可执行脚本。

## 测试与验证

- 测试选中股票、缓存命中、强制刷新和旧请求失效。
- 测试自选股更新后重新关联，以及删除当前股票后清空。
- 测试图表消息中包含成交量和正确的市场分类。
- 运行本次修改范围的格式、ESLint、TypeScript 编译和 Webpack 生产构建。
- 在 Extension Host 中验证单击树节点会更新侧栏图表，且不打开编辑器标签页。

## 非目标

- 不移除或重写现有“自选股详情”编辑器 Webview。
- 不把原生 Tree View 改写成 Webview 列表。
- 不改变 AxData WebSocket 行情协议。
- 不新增分时数据源或历史 K 线功能。
